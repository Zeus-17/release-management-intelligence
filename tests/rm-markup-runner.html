Q-15 / Q-17. Two modes (serve the repo root over HTTP):
?mode=probe (default): fills every user-text field of the tool's data with markup that would run script (<img onerror>) and renders every screen; PASS = nothing executed and no element was created from the text.
?mode=snapshot: renders every screen with ordinary data (deterministic ids) and compares a hash of each screen with rm-snapshot-baseline.json; PASS = escaping changed nothing a normal user sees. Add &write=1 to print a new baseline.
